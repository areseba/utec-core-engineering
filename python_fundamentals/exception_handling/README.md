# exception_handling

Contiene script de Python - Manejo de excepciones

## Script

- `safe_print_list.py` Escribe una función que imprima x elementos de una lista.

- `safe_print_integer.py` Escribe una función que imprima un entero con "{:d}".format() seguido de una nueva línea.

- `safe_print_list_integers.py` Escribe una función que imprima los primeros x elementos de una lista.

- `safe_print_division.py` Escribe una función que divida dos enteros.

- `raise_exception.py` Escribe una función que lance un TypeError.
