# Control_flow

Esta carpeta contine script de python3

## Script

- `positive_or_negative.py` Crea un script que asigne un número entero aleatorio a una variable llamada number

- `last_digit.py` Asigne un entero aleatorio a number

- `print_alphabt.py` Imprime el alfabeto en minúsculas excepto q y e.

La salida debe ser continua (sin espacios, sin nuevas líneas excepto al final).

Solo puedes usar print una vez en tu código

- `print_hexa.py` Imprime números del 0 al 98 en decimal y hexadecimal.

- `print_comb2.py` Imprime números del 0 al 99 formateados como números de dos dígitos, separados por coma y espacio.

El último número no debe ir seguido de coma.

- `print_comb3.py` Imprime todas las combinaciones únicas de dos dígitos diferentes del 0 al 9.
